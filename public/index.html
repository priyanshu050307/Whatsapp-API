FEATURES

Enterprise Grade Gateway Features

Everything you need to send programmatical updates reliably without getting banned.

Instant Async Queue

API requests resolve in under 10 milliseconds. The system queues messages and dispatches them sequentially in the background.

Anti-Spam / Anti-Ban Guard

Enforces a natural, randomized delay (500ms to 1.5s) between message transmissions to emulate human typing patterns.

Secure Multi-Tenancy

Completely isolated browser execution threads and message stores. Your sessions and credentials are 100% private.

Busy & Tally Integration

Out-of-the-box support for Busy and Tally custom SMS/WhatsApp HTTP request endpoints. Zero coding required.

Automated Credit Refunds

Fair billing logic. 2 credits are charged for multi-part (Media + Caption) sends, and credits are auto-refunded instantly if a send fails.

Media & Document Attachments

Send PDF bills, image receipts, audios, and document attachments smoothly via base64 encoding injection.

ABOUT US

Bridging Software & Real-Time WhatsApp Messaging

WaGateway is a modern SaaS platform designed to offer businesses a plug-and-play REST API bridge to connect their systems (accounting, ERPs, CRMs) to WhatsApp.

We realized standard business APIs are hard to set up, heavily restricted, and expensive. That's why we engineered a secure, multi-tenant solution that runs directly via QR-code device linking, keeping installation simple and running costs low.

Master Admin Password Help
Restricted Access Notice: Master Admin credentials are hardcoded or configured in environment variables (`.env`) for maximum security.

To update or recover the Master Administrator Password:

  1. Access your server hosting directory or configuration environment.
  2. Modify the MASTER_ADMIN_PASSWORD variable in the .env file.
  3. Restart the Node.js application process.

Default emergency password configured in development environment is admin123.
